## Reading the scores

- **The trust quartet tops the ranking** (Liquidity Box, Diligence Gates, Calculator, Yield Breakdown = ranks 1–4). These are exactly v5's stated differentiators — the score independently confirms they earn MVP priority, because they sit on the fears *all four personas share*.
- **\* The "What you own" card scores 8, not top-tier — but stays MUST.** Its lower score is a scoring artifact: only P1 rates it HIGH (it's most acute for the scam-fear), while others rate it MED. Strategically it's the signature comprehension surface and the anchor of Property Detail, so it overrides pure score → **MUST**. *(A good example of score informing, not dictating.)*
- **† KYC / Token ACL scores 6 but is non-negotiable** — a legal/compliance requirement under Reg A+, not a discretionary feature. **MUST** regardless of score.
- **P4-only features cluster at the bottom** (tax center, auto-reinvest). Correct for MVP: they serve the secondary persona's *wants* (not shared fears), so they're COULD / post-MVP without hurting the core.
- **P2's distinctive features** (on-chain receipts, external wallet, secondary market) score mid-pack — enough to include in a layered "provable on demand" way, not enough to reshape the primary flow. Matches the invisible-by-default / provable-on-demand resolution.

## How this feeds forward

This ranking sets **build priority and screen emphasis** for Freya's Phase 2 (UX Scenarios → Specs). The MUST tier defines the non-negotiable content of the signature **Property Detail** screen and the **Investment Flow**; SHOULD tier shapes Home / Portfolio / Learn; COULD tier is explicitly deferred and flagged in the design log so nothing silently expands MVP scope.
