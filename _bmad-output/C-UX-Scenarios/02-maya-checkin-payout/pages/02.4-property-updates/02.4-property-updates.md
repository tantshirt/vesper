# 02.4-property-updates

**Previous:** ← [02.3 Income](../02.3-income-distributions/02.3-income-distributions.md)

## Metadata
Scenario 02 · Per-property update feed · Mobile PWA · Authenticated · Tokens: [D-Design-System](../../../D-Design-System/00-design-system.md)

## Overview
**Purpose:** Sustain trust with a monthly operator update **even when nothing dramatic happened** — the anti-RealT commitment ("silence kills trust faster than underperformance"). **Success:** Maya reads a plain, honest month and trusts the operator. **Exit:** back / earlier updates.

## Key objects
- `upd-current` — latest update card: month · **named operator** (Lantern Residential) · key stats (occupancy, reserves, rent-on-time) · plain-language note (incl. minor items like a reserve-covered repair).
- `upd-quiet-note` — "We send an update every month — even the quiet ones."
- `upd-history` — list of prior monthly updates (tap to expand).

## States
Default (routine month) · **material event** (elevated styling, links to detail — kept honest, not alarmist) · first-update.

## Notes
Ties to O5 (≥95% on-time updates). The "boring is good" framing is deliberate — a healthy, uneventful month, reported anyway, is the trust product. Named operator reinforces "who's managing this."
