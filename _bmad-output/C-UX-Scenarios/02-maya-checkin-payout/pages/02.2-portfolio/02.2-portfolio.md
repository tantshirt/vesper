## Metadata
Scenario 02 (also S3 Priya) · Portfolio tab · Mobile PWA · Authenticated · Tokens: [D-Design-System](../../../D-Design-System/00-design-system.md)

## Overview
**Purpose:** "What do I own and earn?" — total value, allocation, and per-holding performance. Also the honesty surface for **concentration** (Priya's fear). **Success:** Maya sees each holding's value + income; concentration is visible, not hidden. **Exit:** tap a holding → Income (02.3).

## Key objects
- `pf-total` — total value + all-time return + income earned.
- `pf-alloc` — **allocation bar by market** + legend; explicit **≤35% concentration guardrail** check. If breached (e.g. Tampa 71%), show a calm warning + "consider diversifying" nudge (never hide it).
- `pf-holdings` — per property: name (Fraunces), ownership %, lifetime income, current value, this-month distribution → tap to Income.

## States
Default · single-holding · concentration-breach (warning shown) · loss state (value down → loss color + `−`, calm) · empty.

## Notes
Serves both P1 (see it grow) and P4 (allocation control + concentration discipline, O5). Gains/losses always paired with a sign.
