# 01.3–01.5 — Set up & Fund (onboarding gate)

**Previous:** ← [01.2 Property Detail](../01.2-property-detail/01.2-property-detail.md) · **Next:** → [01.6 Calculator](../01.6-calculator-order-preview/01.6-calculator-order-preview.md)

> Represents scenario steps **01.3 Signup (Privy)**, **01.4 Identity & Eligibility (KYC + Reg A+)**, **01.5 Add Money (fiat→USDC)**. Shown in the flow prototype as one condensed "Set up" screen; each is its own full page in production.

## Metadata
Scenario 01 · Flow gate · Mobile PWA · Triggered when an un-onboarded user taps **Invest** on 01.2 · Tokens: [D-Design-System](../../../D-Design-System/00-design-system.md)

## Overview
**Purpose:** Get a first-timer account-ready without crypto friction, then return them to the calculator. **Success:** account + wallet created (Privy, passkey), identity verified, USDC funded — all in "about a minute," crypto invisible. **Exit:** → 01.6 Calculator (preserving the property + intent).

## The three sub-steps
1. **01.3 Signup (Privy)** — passkey / Face ID; embedded self-custodial wallet **pre-generated invisibly**. Copy: "No seed phrases." 
2. **01.4 Identity & Eligibility** — KYC (Persona); **Reg A+ per-investor limit** shown as a calm note ("invest up to 10% of income/net worth per year — we'll track it"), never a wall. Eligibility recorded in Convex → enforced on-chain via Token ACL.
3. **01.5 Add Money** — card/ACH → USDC (Privy + Bridge). Framed as "Add money," amount shown in dollars.

## States
Each step: default · in-progress · verified/funded (✓) · error (inline, calm, no dead-ends) · restricted jurisdiction (waitlist, not a wall).
