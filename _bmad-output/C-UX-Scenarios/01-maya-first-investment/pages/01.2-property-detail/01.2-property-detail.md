## Overview

**Page Purpose:** Let any visitor understand a *specific* property well enough to answer the three core fears — **"Is it real?" · "Will I get paid?" · "Can I get out?"** — and decide to invest. This is the screen that carries the entire trust quartet.

**User Situation:** Maya (P1) arrives guarded, from a friend's link, on the train, on her phone. Also the hub for Priya (yield depth), Kai (on-chain proof), and Devin (informed risk reading).

**Success Criteria:** Visitor can state in her own words *what she'd own, where the return comes from, and how she'd exit*; taps **Invest** with confidence (feeds O3 comprehension + O2).

**Entry Points:**
- From **Explore** (tap a property card) — primary
- Deep link (shared) — lands here pre-auth
- From **Learn / market explainer** (Devin, S5)

**Exit Points:**
- **Invest** → 01.6 Calculator & Order Preview (auth/KYC gate triggers here if not signed in)
- **On-chain proof** → 04.2 On-chain Proof/receipts (provable-on-demand, Kai)
- Back → Explore

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default | Property open for investment | Full content, invest bar active | Invest, explore sections |
| Loading | Data fetching | Skeletons on metric/yield/liquidity; no layout shift (CLS<0.1) | — |
| Funding closed | Fully funded / offering closed | Invest bar → "Fully funded" (disabled) + "Notify me" | Watch, view secondary |
| Not yet eligible | Unauth or pre-KYC taps Invest | Invest proceeds to signup/KYC gracefully (not a wall) | Sign up / verify |
| Restricted jurisdiction | Reg A+ geo/eligibility fails | Calm explainer, no dead-end; offer waitlist | Join waitlist |
| Error | Data load fails | Inline retry, preserve scroll | Retry |

## Interactions

- **Tap headline metric / "What you own" nodes / yield rows / gates** → progressive disclosure (no navigation away).
- **Invest** → auth/KYC gate if needed, then calculator. Atomic-DvP framing begins downstream, not here.
- **On-chain proof** → dedicated proof view (Kai).
- **Share (⋯)** → public link (respect Reg A+ solicitation rules — see Open Questions).

---

## Technical Notes

- Public + SSR for the pre-auth marketing value, but **mind Reg A+ marketing/solicitation constraints** on public offering language (legal, not just SEO).
- Numbers come from Convex (entitlement authority) reconciled to chain; on-chain proof deep-links resolve via Helius/explorer.
- Performance: LCP<2.5s, CLS<0.1 (money must not shift); hero image <400KB.
- Crypto vocabulary forbidden in visible copy (wallet/gas/tx/mint) except inside the on-chain proof view.
